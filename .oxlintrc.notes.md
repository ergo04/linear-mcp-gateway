# oxlint notes

`typescript/no-unnecessary-condition` is deliberately not enabled.

It flags 9 places in `apps/gateway/lib/linear.ts` where a `?? fallback` contradicts a
type declared as non-nullable — for example `RawMilestoneNode.progress` is `number` while
the code writes `m.progress ?? 0`. Each one needs a decision rather than an autofix: either
trust the declared type and drop the fallback, or widen the type because Linear really can
return null there. Tracked separately so it does not block lint.
